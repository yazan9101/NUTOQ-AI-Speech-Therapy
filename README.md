# NUTOQ - AI Speech Therapy Platform

## 📌 Overview
A web-based platform designed to help adults who stutter improve their speech using Speech-to-Text (STT) technology.

## 🚀 Features
- Real-time speech evaluation
- Adaptive learning system
- Instant feedback (e.g., "slow down", "take a breath")
- Progress tracking dashboard
